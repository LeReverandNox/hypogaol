A Brainstorming Keepsake · August 2, 2026

The Naming of the Warden

Every vault needs a name before the world may know it. This one had only a placeholder — tomb‑fido2 — a working label for a Rust CLI that unlocks a LUKS volume with a FIDO2 hardware key. It was time to give it a real one, ready to stand in public.

The Brief

  • Playful, with a strong point of view — no boring technical name
  • Must still carry the tomb / buried‑data feeling
  • No direct reference to "tomb" or "fido2"
  • Not already claimed by a popular open-source project (checked via GitHub)

Chapter III

Into the Burial Ground

Direction shifted: stop borrowing shelter-words from other tongues, and go straight at the tomb/burial lexicon in English.

Cairnalready used by many projects
Hypogeum Greek — underground chamber, temple, or tomb kept — the anchor

GitHub check: only a small, unpopular student multiplayer game (mikymaione/Hypogeum) uses it — no major collision. It became the user's favorite so far, and the root to build from rather than the final word itself.

Chapter IV

The Blending

Technique: Concept Blending. Hypogeum became raw material to mutate, not the destination itself.

Hypogeon blend of Hypogeum + Dungeon — shares the "ge" bridge, keeps the archaeological root, adds a playful treasure-vault echo
Hypocrypt blend of Hypo + Crypt — sounds like "hypocrite." No collision found, but "-crypt" is a crowded suffix in this exact niche (Picocrypt, Cryptomator...) — risks reading as "yet another cryptname"
A tangent, not a candidate: Hypogeal — the adjective form of hypogeum ("underground, subterranean") — is also the botanical term for seeds that germinate underground. A natural bridge back to the earlier Svalbard Seed Vault thread.
Hypogaol blend of Hypo(gean) + Gaol — referencing Bloodborne's "Hypogean Gaol." Zero GitHub collisions — only game-lore pages. found
The name has been found
Hypogaol
"Sealed until touched."

hypo- (under, beneath) + gaol (the archaic spelling of jail) — a name that is, at once, a real word for an underground chamber and a wink at Bloodborne's Hypogean Gaol. It hits every mark: playful, strong point of view, stays in the buried/underground register, no direct "tomb" or "fido2" — and, checked, nobody else on GitHub has taken it.

The name proved fertile: it generated a coherent identity on its own — mascot, mark, palette, tagline — rather than needing one forced onto it.
Chapter V

Trial by PMI

Before committing, the sole surviving candidate went through a Plus / Minus / Interesting pressure test.

+ Plus

  • Zero OSS/GitHub collision, confirmed.
  • Strong parti-pris via the Bloodborne/Soulsborne reference — distinct personality, no literal tomb/fido2 reference.
  • The name proved fertile on its own, generating mascot, mark, palette and tagline unforced.

− Minus

  • "Gaol" pronunciation friction for readers unfamiliar with the archaic spelling — mitigated by a planned README pronunciation note (the k3sup precedent).
  • The Bloodborne reference lands only for players who know it; to everyone else it reads as an invented word — the same risk "tomb" never had to face.

? Interesting

  • The name works on two independent levels at once — a real archaeological term (hypogeum/hypogean) and a specific gaming Easter egg — so it lands even for people who miss one of the two references.
VERDICT — Pluses outweigh minuses; both minuses already mitigated or acceptable. Proceed with Hypogaol.
Chapter VI

The Identity Takes Shape

A name this fertile grew a full identity around it — a mascot, a mark, a palette, and the boundary between where flavor lives and where it must never intrude.

The Mascot — Hypo

Hypo A small stone gargoyle warden — Victorian coat, brass buttons, a ring of ornate keys at the belt, a lantern in hand. A deadpan guardian character for docs and README. Its rune-circle mark and a wheelbarrow-adjacent name ("Barrow") were both tried and set aside before landing here — "Hypo" is a short, friendly nickname callback to the "hypo-" root, distinct from the formal project name. A small ASCII-art banner of Hypo and his lantern is planned for a successful unlock.

The Mark

A gothic rose-window tracery circle. At its center, a keyhole shape fused with a FIDO2 security-key silhouette — a subtle nod to the hardware mechanic. Rose windows and gargoyles are both authentic elements of the same real Gothic cathedral architecture, so the mark and the mascot cohere around one consistent world — cathedral and prison at once — deliberately distinct from the glowing rune-on-stone language of the user's earlier project, runed.

The Palette

Moss Greenbase
Lantern Amberaccent — unlock only

Dark stone grey and moss green form the base. A single warm lantern-amber accent is reserved for the unlock/success moment — echoing Bloodborne's lamp checkpoints.

The Tagline

  • "Locked in stone. Opened by touch."
  • "No warden but the one you carry."
  • "Buried deep. Unlocked by touch."
  • "One key. One touch. Nothing else gets in."
  • "Sealed until touched."

Branding Stops at the Door

A full warden vocabulary was drafted for the CLI verbs, then rejected — too abstract to memorize. A crisis-use tool needs zero-cognitive-overhead verbs, not puns to decode under stress.

rejected — the warden's vocabulary
parole (unlock) remand / commit (lock) deputize / induct (enroll) discharge (revoke) roster (list) found (init) inspect (doctor)
locked — plain and literal
unlock lock enroll revoke list init doctor

Theming lives only at the top — name, mascot, mark, tagline, banner. Subcommands, README, and error messages stay plain, literal, human-friendly, with zero flavor.

Renaming "Tomb" in the Code

The internal domain term for the encrypted container needed a generic, theme-independent replacement — one that wouldn't need to change if the branding ever evolves again.

tomb ➔ volume

also considered: container vault — volume matches LUKS/cryptsetup's own native terminology

Chapter VII

What This Session Taught

Insight 01 — Specificity Beat Vocabulary

Abstract dictionary words, in any language, never sparked. The breakthrough came from one specific, textured cultural reference — Bloodborne's Hypogean Gaol — rather than a generic "cool word."

Insight 02 — One Recurring Principle

Flavor belongs at the top — name, mascot, mark, tagline. Literal clarity belongs everywhere the user depends on it under stress — CLI verbs, README, error messages. The same principle that shaped Epic 1's "plain-language, zero cognitive overhead in crisis" requirement, recurring here in branding.

Insight 03 — An Emerging Signature

Hypogaol — grounded, Victorian-gothic — deliberately contrasts with the user's prior project "runed" — cosmic, Lovecraftian. Dark and atmospheric each time, but tonally distinct per project, not a repeated formula.
