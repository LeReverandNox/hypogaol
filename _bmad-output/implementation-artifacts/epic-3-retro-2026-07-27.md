- Production incidents: 0. Post-merge regressions: 0.

## What Went Well

- Epic 1's lesson ("spike before locking a design around external tool behavior") fully landed this epic: 3.2's Task 0 was an explicit, empirical `cryptsetup resize` keyring spike run *before* any port signature was written — the pattern working as originally intended, after only half-applying in Epic 2.
- Zero pauses, zero regressions, zero production incidents across all three stories.
- A real security gap (world-readable contents on a never-writably-unlocked tomb's first read-only mount) was caught by review, not discovered in the field.
- 3.2's genuinely ambiguous "how does resize even read current size" design question was worked through deliberately in the story's own Dev Notes rather than guessed at — though review still found two real bugs in the reasoning (ordering of `read_filesystem` vs. the rejection check; an off-by-one in the idempotent-retry comparison).

## What Didn't Go As Smoothly

- **Marker-bleed is still the most persistent bug class in this codebase.** Explicitly checked as its own task in every Epic 3 story, it still slipped into the initial diff twice — the proactive check catches it at review time, but doesn't prevent it at write time.
- **A new recurring pattern surfaced**: `let _ = luks.close(&mapper)` silently swallowing a rollback-path failure has now been flagged "pre-existing, not this story's problem" three separate times (`create.rs`, `resize.rs`, and again for `unlock.rs` in 3.3) — true individually each time, but nobody's problem three times running is how it stays unfixed.
- **Hardware runs keep finding what review and unit tests can't** — consistent with Epic 2's read that this is inherent to a tool whose correctness depends on real external hardware/filesystem interop, not a process gap.
- **Three backlog items (sudo docs, LICENSE/branch-protection, progress-reporting) have now carried unaddressed across three consecutive retrospectives.**
- **Release automation (Story 1.3) still hasn't been exercised on a real tag**, unchanged since Epic 1.
